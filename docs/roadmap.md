# Roadmap do SlideFlow AI

## V1 — Geração básica

- [ ] Receber um tema e arquivos de referência.
- [ ] Extrair texto de PDF e TXT.
- [ ] Gerar roteiro estruturado com modelo local.
- [ ] Criar apresentação PowerPoint.
- [ ] Validar estrutura e conteúdo da saída.
- [ ] Criar testes automatizados.

## V1.1 — Qualidade e confiabilidade

- [ ] Validar o JSON gerado pelo modelo.
- [ ] Melhorar tratamento de erros.
- [ ] Controlar tamanho do conteúdo enviado ao modelo.
- [ ] Adicionar notas do apresentador.
- [ ] Melhorar referências e rastreabilidade das afirmações.

## V2 — Modularização e agentes

- [ ] Separar extração, geração e apresentação em módulos.
- [ ] Definir contratos de entrada e saída.
- [ ] Criar agente de elaboração do roteiro.
- [ ] Criar agente revisor.
- [ ] Implementar orquestrador.
- [ ] Registrar resultados e erros das etapas.

## V3 — Apresentações avançadas

- [ ] Criar layouts e temas visuais.
- [ ] Incluir imagens e diagramas quando apropriado.
- [ ] Adicionar pesquisa na internet como opção.
- [ ] Criar interface para submissão de temas e fontes.
